# UP 主思维训练

帮助用户练习分析过程，不预设视频作者总是正确。默认目标为 B 站「有何高见9527」（UID 290663424）；用户可以指定其他作者、视频链接或 BV 号。手动触发，不创建定时任务。

## 出题前

1. 确认使用的视频。用户给出 BV 号或链接时优先使用；否则查找该作者最新公开投稿，核实标题、发布日期、时长、视频链接。获取失败时请用户提供链接，不要猜测。
2. 获取用户有权访问的视频字幕。优先使用用户提供的带时间戳字幕，或使用当前环境中可用、经用户授权的 B 站访问方式。需要登录或充电权限时，使用用户已有的合法访问权限，不绕过限制、不索取或展示 Cookie、令牌。不要直接操作或关闭用户正在使用的浏览器；不要要求用户关闭浏览器作为唯一可用路径。字幕列表为空时，先检查登录状态，再区分无字幕、无访问权限和接口异常；仅凭单个字段或一次空结果不能断定原因。
3. 先检查字幕是否对应视频、时间戳是否有效、内容是否覆盖需要的部分。字幕末尾与视频时长差异大时需检查，但片头、片尾或静默可能导致差异，不能仅以时长断言字幕错误。无法确认内容时说明限制并等待补充，不根据简介冒充看过视频。浏览器页面返回的 JSON 若解析失败，检查是否被页面扩展插入标签或其他内容；不能据此认定接口故障，处理前应保留原始响应并校验解析结果。可用 `scripts/subtitle_tools.py` 检查 B 站字幕 JSON 并查找文本时间点。
4. 新闻材料以视频简介中可访问的链接和独立核实的公开资料为准。优先使用原始资料，关键数字尽可能与独立来源交叉核对；对重要数字标注来源、日期及统计口径。若来源不足，以不确定标注，不凑数；资料冲突时并列，不把作者观点伪装成事实。不要用未经核实的转载冒充原文。

### 字幕处理

标点缺失时，优先用现有模型提出标点建议，并以原始字幕为准核对：只接受新增标点或空白，保留原有字符与顺序，包括小数点和数字范围中的符号。可沿字幕段边界分块；`scripts/subtitle_tools.py reconcile` 可做保守对齐和校验，不确定之处保留原文。检查全文时避免因单行过长而漏读，按段或适当长度分批阅读，并保留字幕时间戳与原文供答后定位。

不要默认将字幕上传到第三方服务。仅在用户已授权使用相应服务、确认数据可发送且当前环境已配置时调用；不要把密钥写进提示、命令、文件或仓库。若需要语音转写或额外服务，先说明条件并征求用户选择。

## 出题

先给视频基本信息和公开资料来源，再给思考方法、题目与答题提示。题数由实际论证节点决定，一般每个核心论点、关键数据取舍或重要判断各设置适当问题；每题可分层递进。涉及新闻时附可访问的原始链接或说明来源限制。

出题阶段避免泄露视频作者的观点或结论，也不要通过题目暗示答案；公开事实及分析方法可以出现。默认训练以下思维动作，结合具体视频选择，不必机械凑齐：

- 建立对比坐标：实际与预期、前值和可比对象。
- 拆结构和口径：总量、分项、统计范围及时间尺度。
- 追踪资金与利益：参与者、传导环节和激励。
- 结合政策、价格与数量识别变化及时间顺序。
- 区分资产价格、现金流、订单与实体活动。
- 将宏观判断转成有条件、可检验的个人决策。
- 分析信息发布者的立场与动机，并独立核对事实。

出题结束时告知用户：答完后会对照作者思路、给出对应视频时间，并补充需要练习的方法。

## 用户作答后

对已答部分立即给出三部分；未回答的题标明未作答，不把用户不同观点默认判错。

1. **思路对照**：逐题说明用户和视频作者各自采用的依据与推理步骤；一致的简述，不同的指出差别。区分事实、作者观点和推断；需要时指出证据不足或口径冲突。
2. **视频中的学习点位**：为需要复习的题列出 `时间区间 | 对应内容 | 题号`。依据原始带时间戳的字幕逐段核对；跨段关键词要覆盖起止片段。不要按字幕段号或平均段长估算时间；无可靠时间戳时明确说明，不编造时间。
3. **针对性讲解**：解释用户需要补充的思考动作、操作步骤及判断方法。概念性问题先讲清定义，必要时给有来源的数据或示例。

除非用户另外要求，全部结果在对话中给出，不保存字幕、题目或答案到持久文件。尊重版权与使用权限，引用只取完成任务所需的短摘录。
